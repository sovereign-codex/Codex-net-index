# Codex Net Index

Codex Net Index is the **memory layer of Codex‑Net**.

It stores structured knowledge about:

- research threads
- repositories
- codex entries
- governance decisions
- AVOT assignments
- ontology definitions

This repository contains **no runtime logic**.  
It acts as the persistent knowledge graph for the Codex ecosystem.

## Structure

threads/ – Research and development threads  
repos/ – Profiles describing each repository  
codex/ – Canonical knowledge entries  
decisions/ – Governance decisions produced by the Council Engine  
relationships/ – Cross-links between threads, repos, and codex entries  
ontology/ – Domain definitions and signal taxonomy  
avot-links/ – Assignments linking AVOT roles to threads and repos
